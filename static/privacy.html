Kebijakan Privasi

Maktabahrizqy adalah perpustakaan digital pribadi. Website hanya mengizinkan akun Google pemilik yang ditentukan di pengaturan server.

Data yang diproses

Aplikasi memeriksa alamat email terverifikasi melalui login Google. Untuk sinkronisasi PDF, Google meminta izin Drive hanya baca. Izin Google ini secara teknis dapat membaca seluruh Drive; namun kode aplikasi menggunakan izin tersebut untuk memeriksa folder Maktabahrizqy yang telah ditentukan dan subfoldernya. Aplikasi tidak memindahkan, mengubah nama, membagikan, atau menghapus berkas Google Drive.

Catatan membaca dan PDF

Judul, kategori, catatan, status, dan halaman terakhir tersimpan dalam database privat pada server tempat aplikasi dijalankan. Jika PDF dibuka melalui pembaca internal, server dapat menyimpan salinan PDF dan gambar sampul pada penyimpanan privat untuk mempercepat pembacaan. Tautan PDF biasa hanya dibuka melalui situs tujuan dan tidak otomatis dilacak oleh aplikasi.

Akses dan penyimpanan

Token akses Google disimpan dalam bentuk token refresh yang dienkripsi di server. Sesi memakai cookie HttpOnly. Jika aplikasi ditempatkan di layanan hosting, data serta cache diproses pada infrastruktur penyedia hosting tersebut. Pemilik wajib mengamankan pengaturan server dan menyiapkan backup berkala.

Penghapusan dan pencabutan izin

Tombol Hapus dari Katalog menghapus metadata dan progres bacaan di aplikasi, bukan berkas di Google Drive. Salinan PDF yang pernah dibuat oleh pembaca internal mungkin tetap ada di cache hingga dibersihkan oleh pemilik server. Pemilik dapat mencabut akses Google dari pengaturan keamanan Akun Google, kemudian menghapus data serta cache server ketika tidak lagi menggunakan layanan.

Pembagian data

Website tidak mempunyai fitur menjual data atau menampilkan katalog kepada pengguna lain. Google dan penyedia hosting tetap memproses data yang diperlukan untuk fungsi login, penyimpanan, dan layanan.
